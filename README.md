# しゃべる柿の木｜開発メンバー確認用プロトタイプ

同じプロジェクトの開発メンバーが、画面デザイン・導線・ゲームロジックを確認するためのモバイル向けプロトタイプです。

現在はGoogle認証、会話AI、センサー、共有DB、給水機器と接続していません。すべての状態はブラウザの `localStorage` に保存され、共同参加人数やランキングはサンプルデータで再現します。

水やりは、土壌の乾燥をきっかけに20分限定で始まる「水やりバケツリレー」として実装しています。参加者は10ptを受け取り、50タップ達成で全員に30pt、80タップ達成で翌日のログインボーナスが1.5倍になります。参加者から完全ランダムで「本日の一番水やり当番」も選ばれます。

## ローカル起動

```bash
npm run dev
```

ブラウザで `http://localhost:4173` を開きます。確認時点では外部APIや認証情報は不要です。

管理画面プロトタイプは `http://localhost:4173/#admin` で開けます。

## 主なレビュー項目

- 8問診断から推し柿決定までの離脱しにくさ
- ホームから共同水やりミッションへの導線
- 50・80タップのマイルストーンとポイント配分
- 会話、ランキング、ピンバッジ、10問クイズの回遊性
- 天候・時間・土壌状態に連動する背景と、9種類の柿キャラクター状態
- マイページと管理画面で必要なデータ項目

本番実装時は、共同ミッション、ポイント、ランキング、履歴を共有DBへ移し、サーバー側で給水上限と抽選を確定する想定です。

## ポイントで遊べる機能

- 見守りランキング：デモ参加者と自分を獲得ポイント順に表示
- ピンバッジ：0 / 50 / 150 / 300 / 500 / 1,000ptで6種類を段階解放
- 見知不柿クイズ：全10問、正解ごとに10pt、全問正解で追加50pt

クイズでポイントを獲得できるのは1日1回です。同日の2回目以降は、解説を読み直せる復習モードになります。

## 天候・状態イラストの確認

ホームの背景は、時刻・季節・日ごとの天候シミュレーションに応じて「晴れ／くもり・風／雨／雪／夜」の5種類を自動表示します。柿キャラクターは、土壌水分・気温・水やり履歴などに応じて「元気／乾燥／暑い／寒い／雨の日／強風／おやすみ／水やり成功／収穫」の9状態に切り替わります。

開発レビューでは、ホーム上部の「状態イラスト確認」ボタンで全9状態を順番に表示できます。最後まで進むと自動表示へ戻ります。外部の天気APIには未接続で、公開時もブラウザ内の判定だけで動作します。
