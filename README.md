# しゃべる柿の木

会津の見知不柿を、診断・会話・水やりを通して身近に感じるモバイル向けWebアプリです。

水やりは、土壌の乾燥をきっかけに20分限定で始まる「水やりバケツリレー」として実装しています。参加者は10ptを受け取り、50タップ達成で全員に30pt、80タップ達成で翌日のログインボーナスが1.5倍になります。参加者から完全ランダムで「本日の一番水やり当番」も選ばれます。

## ローカル起動

```bash
npm run dev
```

ブラウザで `http://localhost:4173` を開きます。外部APIや認証情報は不要です。

管理画面デモは `http://localhost:4173/#admin` で開けます。

## データについて

フェイクログイン、診断結果、会話、水やり履歴、ポイントはブラウザの `localStorage` に保存されます。静的サイトとしてそのまま公開できます。

共同参加人数や他の参加者のタップは、単体で公開しても体験できるようデモデータで再現しています。実運用時は、このミッション状態を共有DBへ移す想定です。

## ポイントで遊べる機能

- 見守りランキング：デモ参加者と自分を獲得ポイント順に表示
- ピンバッジ：0 / 50 / 150 / 300 / 500 / 1,000ptで6種類を段階解放
- 見知不柿クイズ：全10問、正解ごとに10pt、全問正解で追加50pt

クイズでポイントを獲得できるのは1日1回です。同日の2回目以降は、解説を読み直せる復習モードになります。
